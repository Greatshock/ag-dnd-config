# Каталог AG D&D Hub

Чтобы запланировать появление карточки, добавь в запись модуля в `registry.json` поле `publishAt`. Например, эта строка откроет карточку 1 декабря 2026 года в 19:00 по Минску.

```json
"publishAt": "2026-12-01T19:00:00+03:00"
```

Укажи дату, часы, минуты, секунды и часовой пояс. Для того же момента в UTC подойдёт `2026-12-01T16:00:00Z`. Без поля карточка видна сразу. При ошибке в дате хаб скрывает карточку до исправления записи.

Расписание работает в AG D&D Hub с версии 1.5.7 по часам устройства. Оно управляет видимостью карточки в каталоге. Сам файл реестра и ссылки в нём публичны с момента коммита.
